# Motor Vehicle Insurance Portfolio Analysis

This project/repositry performs a comprehensive data analysis and machine learning pipeline in R using the **Dataset of an actual motor vehicle insurance portfolio**, published by Josep Lledó and Jose M. Pavía on **July 30, 2024** via [Mendeley Data](https://data.mendeley.com/datasets/5cxyb5fp4f).

### Dataset Overview

**Type** : Anonymised microdata from a Spanish non-life motor vehicle insurance portfolio.
**Volume** : 105,555 rows and 30 variables.
**Timeline** : over three full years (November 2015 to December 2018).

### Project Goals

The objective of this repository is to explore risk heterogeneity and contract dynamics by:

1. Cleaning and preprocessing transactional policyholder profiles.
2. Building regression models to predict claim frequencies, claim severities and evaluate (pure) premium pricing.
