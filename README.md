Hi there!

This is an example of an interactive html report using RMarkdown's tabsets (`.tabset`) and accordions (`.accordion`).

This template provides an idea of how to:

1.   nest tabsets (tabs inside tabs),

2.   nest accordions (accordions inside accordions), and

3.   nest accordions inside tabs in your report.

Note: this structure is ideal for short to medium reports. You can edit the template file structure to create your report.

Using this structure helps to maximize information density while keeping the document cleanly organized instead of one infinitely long webpage hence avoiding the "Scroll of Doom".

The contents inside the .Rmd files provides an idea to help you get started, edit it and make it your own. Take note of the main headers and subheaders so as to avoid breaking the `.tabset` structure.

To see the interactive report template check: <https://rodneyzt.github.io/report/>
