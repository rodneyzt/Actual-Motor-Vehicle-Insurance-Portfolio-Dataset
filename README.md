This project explores the Actual Motor Vehicle Insurance Portfolio Dataset by Jose M.Pavia found at data.mendeley.com/ published in July 30, 2024.

The data is for a non-life motor insurance portfolio and spans over three full years (November 2015 to December 2018).

To see the interactive report template check: <https://rodneyzt.github.io/Actual-Motor-Vehicle-Insurance-Portfolio-Dataset/>
